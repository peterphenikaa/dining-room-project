Dự án quản lý phòng ăn, bàn ăn
Ngày báo cáo: 17/07/2026
1. Tổng quan Kiến trúc & Hạ tầng
- Docker hóa thành công: Đã thiết lập Docker Compose bao gồm 2 container (MySQL 8 và Express App). - Môi trường Phát triển (Dev): Tích hợp thành công Nodemon và cơ chế Hot-Reload, tự động biên dịch TypeScript sang JavaScript ngay khi có thay đổi code, tiết kiệm thời gian khởi động lại server.- Cơ sở dữ liệu: Triển khai chuẩn TypeORM Migrations thay vì tự động đồng bộ (synchronize). Toàn bộ 5 bảng đã được khởi tạo thành công thông qua script.
2. Thiết kế Cơ sở dữ liệu (Database Design)
Hoàn thiện thiết kế 5 thực thể chính với các ràng buộc khóa ngoại (Foreign Key) chặt chẽ:
- DiningRoom (Phòng ăn) - Bảng Gốc- DiningTable (Bàn ăn)- DiningCabinet (Tủ phòng ăn)- DiningChair (Ghế ăn)- DiningAccessory (Phụ kiện bàn ăn)
Đã áp dụng ràng buộc ON DELETE CASCADE: Khi xóa Phòng ăn, toàn bộ Bàn và Tủ bên trong tự động bị xóa bỏ để tránh rác dữ liệu dư thừa.
3. Kiến trúc Code & Phát triển API
- Kiến trúc chuẩn MVC: Đã phân tách code thành các tầng riêng biệt: Routes (Định tuyến) -> Controllers (Điều hướng) -> Services (Xử lý logic DB). Đảm bảo khả năng bảo trì, mở rộng.- Xử lý Lỗi Toàn Cục (Global Error Handling): Loại bỏ hoàn toàn try...catch lặp lại trong Controller. Tích hợp AppError, catchAsync và errorHandler Middleware để thống nhất định dạng JSON trả về cho mọi loại lỗi trên hệ thống.- API Hoàn thành: Đã hoàn thiện toàn bộ các API CRUD (Tạo, Đọc, Sửa, Xóa) cho thực thể DiningRoom (Phòng ăn).
